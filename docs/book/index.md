# 参考教材

基于教材《C-V2X车联网与车路协同关键技术》（蒋建春、林峰 著），科学出版社，2024年8月第一版。

本教材涵盖了车路协同系统的基础概念、V2X通信技术、C-V2X车联网应用层标准、车联网系统主要功能、车辆V2X消息接收预处理、车路协同路侧感知关键技术以及车路协同防撞预警模型等七个章节的核心内容。

## 章节目录

- [第1章 绪论](/book/ch01)
- [第2章 V2X通信技术分析](/book/ch02)
- [第3章 C-V2X车联网应用层标准分析](/book/ch03)
- [第4章 C-V2X车联网系统主要功能分析](/book/ch04)
- [第5章 车辆V2X消息接收预处理](/book/ch05)
- [第6章 车路协同路侧感知关键技术](/book/ch06)
- [第7章 车路协同防撞预警模型及其设计](/book/ch07)

学习建议：建议按照章节顺序学习，每一章都包含理论知识和实践应用相结合的内容，适合作为车路协同系统相关技术的入门与进阶参考。
