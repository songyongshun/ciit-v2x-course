# 项目规则（Cline Rules）

以下规则适用于本项目的所有工作，必须遵守：

1. **不要尝试构建项目**。请勿运行 `npm run docs:build` 或任何项目构建/打包命令。本项目构建过程存在环境兼容问题，不要尝试解决或绕过它。

2. **当前工作环境是 WSL**。所有命令都在 Windows Subsystem for Linux（WSL）中运行，注意路径（如 `/mnt/c/`）、原生二进制/绑定加载、以及跨文件系统操作的可能差异。请勿据此擅自改动项目依赖以"修复构建"。

3. **凡是涉及安装 package，请暂停并先询问我**。安装或修改任何 npm package / 依赖时，必须先停下来征求我的意见、获得明确同意后再执行，**不要自行安装任何 package**。
